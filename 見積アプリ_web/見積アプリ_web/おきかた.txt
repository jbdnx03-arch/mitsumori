ワークス見積メーカー ── Claudeを開かずに使う版
==================================================

ファイル： index.html （これ1枚だけ。ほかに何も要らない）
あいことば： works2721
             ※ 変えたいときは言ってください。作り直します。

■ これは何か
  いままで Claude の中で使っていた見積アプリを、ふつうのWebページ1枚にしたもの。
  中身（商品マスタ・単価・得意先）は あいことば で暗号化してあるので、
  URL を知られても あいことば が無ければ何も読めません。

■ 置き方（GitHub Pages・無料）
  1. github.com でアカウントを作る（無料）
  2. 右上の ＋ →「New repository」
       名前は何でもよい（例 mitsumori）
       Public を選ぶ。※ 中身は暗号化してあるので単価は読まれません
       （Private にすると Pages が有料プランになります）
  3. できた画面の「uploading an existing file」から index.html をアップロード
     → 下の「Commit changes」
  4. Settings → Pages
       Source: Deploy from a branch
       Branch: main ／ フォルダは / (root)  → Save
  5. 2〜3分待つと
       https://＜ユーザー名＞.github.io/＜リポジトリ名＞/
     で開けるようになる

■ iPhone のホーム画面に置く
  1. Safari でそのURLを開く
  2. あいことば を入れて「ひらく」
     （「この端末では次から聞かない」にチェックが入っていれば次からは素通り）
  3. 下まんなかの 共有ボタン →「ホーム画面に追加」
  4. アイコンから アプリとして立ち上がる

■ 会社のサーバーがあるとき
  index.html をそこに置くだけ。GitHub は要りません。

■ 知っておくこと
  ・はじめて開くときはネットが要ります（PDFを作る部品を読み込むため）。
    2回目からは端末に残るので、電波が弱くても動きます。
  ・「控え」と下書きは その端末の中だけに残ります。
    iPhone と Mac で共有はされません。
  ・PDFは「PDFで保存」を押すと端末に入ります。
    うまく入らないときは「PDFを開く」→ 共有 → ファイルに保存。
  ・ほかの営業さんに使わせるときは、URL と あいことば を教えるだけ。
  ・あいことば は 総当たりに強い作り（PBKDF2 25万回＋AES-GCM）にしてありますが、
    短い言葉なので「社外に出ても即バレはしない」程度のものと考えてください。
    本当に守りたいなら 社内サーバーに置くのが確実です。
